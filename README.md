# KINGSNIPE

KINGSNIPE is the compiled DreamBot dice-betting bot artifact delivered from the prior build session.

## Release artifact

- `releases/KINGSNIPE-fat.jar` — compiled fat JAR from the delivered build.
- Manifest main class: `UltimateDiceBot`.

## Important repository note

The prior sandbox session was reset before this repository was created. Only the compiled JAR was recoverable in the current environment; the original Java source tree, Maven `pom.xml`, and build documentation were not restored. This repository therefore preserves the delivered binary artifact without reconstructing or fabricating source files.

For reproducible source builds and future maintenance, add the original source bundle and Maven project files when available.

## Installation

1. Download `releases/KINGSNIPE-fat.jar` from the repository.
2. Load the JAR using the DreamBot script manager according to your DreamBot installation workflow.
3. Review and configure the bot settings before starting it.

Use the artifact only in environments and game contexts where automation is permitted, and comply with the applicable game and platform rules.
